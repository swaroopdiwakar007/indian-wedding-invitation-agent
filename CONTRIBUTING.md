# Contributing

Welcome: new themes, new scripts and fonts, better traditions notes, lint rules, tests.

## Before you open a PR
- `npm test` passes.
- Every new theme is an original composition. No traced or copied designs, no reproduction of a specific template or brand.
- Traditions notes are reviewed by someone from that tradition where possible. Say who in the PR.
- Sacred text is never generated. Accept it only as user-supplied input.
- Examples use fictional names and obviously fake contacts.

## Theme file shape
Fits, Palette, Motif family, Type, Layout idea. Under 8 KB.

## What will not be merged
- Real couples' details.
- Designs copied from commercial products.
- Features that fetch remote images or send user data anywhere.
