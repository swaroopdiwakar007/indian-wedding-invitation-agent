# Brief intake

Ask for what is missing, in one message. Offer defaults in brackets.

## Required
- Tradition and sub-tradition (Hindu, Sikh, Muslim, Christian, Jain, Parsi, interfaith, secular)
- Region or community, if any (Rajasthani, Tamil, Bengali, Punjabi, Gujarati, Marathi, Malayali, Telugu, Kannada, Kashmiri, Bohri, Goan Catholic...)
- Couple's names, in the order the families want
- Hosts (families or parents) and how they want to be named
- Events: name, date, time, venue, address, dress code if any
- Languages and scripts for the card [English + one regional language]
- Output: HTML, PNG, or both; size [HTML + 1080x1920 PNG]

## Optional
- Colour wishes or ones to avoid (some families avoid black or white)
- Photo of the couple (as a local file; embed as a data URI)
- RSVP contact, website, WhatsApp number
- Livestream link, gift or registry note, accommodation note
- Exact scripture or invocation they want, spelled as they want it

## Rules
- Do not guess dates or venues. Do not invent family names.
- Names in Indic scripts need confirmation of spelling from the person.
- If the muhurat is mentioned, copy it as given.
- Save the brief as `briefs/<slug>.json`. Real briefs are gitignored.
