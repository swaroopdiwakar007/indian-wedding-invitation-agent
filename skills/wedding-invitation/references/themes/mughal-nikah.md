# Mughal Nikah

**Fits:** Muslim weddings: Nikah, Walima
**Palette:** ground #0F3D3E deep teal, ink #F5E9C8 cream, accent #D4AF37 gold, support #7FB7A4
**Motif family:** Jali lattice, arabesque medallion, cusped arch
**Type:** Noto Nastaliq Urdu for Urdu; Cormorant Garamond; Noto Naskh Arabic if Arabic
**Layout idea:** Cusped arch with names, jali band, Bismillah only if supplied

Notes: compose an original motif from this family. Do not trace an existing card. Verify contrast of ink on ground before export.
