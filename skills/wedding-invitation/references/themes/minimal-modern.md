# Minimal Modern

**Fits:** Any tradition that wants restraint; a single sacred symbol optional
**Palette:** ground #FFFFFF, ink #1A1A1A, accent one colour chosen from the families' wishes
**Motif family:** One line-art motif or none
**Type:** Source Serif 4 display; Inter or system sans for details; Noto Serif for the Indic script
**Layout idea:** Names large, date aligned left, everything else small, lots of space

Notes: compose an original motif from this family. Do not trace an existing card. Verify contrast of ink on ground before export.
