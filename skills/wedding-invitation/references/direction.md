# Custom direction

When the couple says "custom" or no theme fits:
1. Write one sentence: the single idea only this couple has (a place, a craft, a family object).
2. Choose one motif from that idea, drawn as inline SVG at most 3 KB.
3. Pick a palette of 4 colours: ground, ink, accent, one quiet support. Check contrast.
4. Pick type: one display, one text. Both must cover the scripts needed.
5. Lay out the card around the names and the date. Everything else supports them.
